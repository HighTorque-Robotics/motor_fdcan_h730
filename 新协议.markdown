#define  TINT32  0x10000
#define  TINT16  0x08000
#define  TFLOAT  0x18000
通过更改发送指令的ID来决定发送以及接收的数据类型，
示例：
id为1：0X08001，cmd={ 0x18, 0x06, 0x00, 0x00 }为int16_t的电压模式下控制方式
id为1：0X10001，cmd={ 0x18, 0x06, 0x00, 0x00, 0x00, 0x00 }为int32_t的电压模式下控制方式
id为1：0X18001，cmd={ 0x18, 0x06, 0x00, 0x00, 0x00, 0x00 }为float_t的电压模式下控制方式


发送协议：uint8_t cmd[] = { mode, query, a1, a2, b1, b2...};

1. mode：表示模式（填写枚举中的数字，需要转换为十六进制）。
2. query,：表示要返回的数据（填写枚举中的数字，需要转换为十六进制）。
3. a1, a2,：数据1，向寄存器中写入的数据。
4. b1, b2...：数据2，向寄存器中写入的数据。
   示例：
   使用速度模式，需要返回模式、错误、位置、速度、力矩，使用的是int16_t的数据类型大小
   static uint8_t cmd[] = { 0x1B, 0x06, 0x00, 0x00 };
   0x1B：在枚举类型中该模式为27，转换为十六进制为1b。
   0x06：返回的数据在枚举中对应的值为06。
   0x00, 0x00：发送的数据数值，小端模式。

## 三、运行模式完整分类

### 3.1 普通单机模式 (motor_control)

每个电机独立发送一条 CAN 帧，支持三种数据类型 (TFLOAT / TINT32 / TINT16)。

| 序号 | 模式枚举 | 模式码 | API 函数 | 参数 | 说明 |
|------|---------|--------|---------|------|------|
| 1 | MODE_STOP | `0x01` | `motor_set_stop()` | 无 | 三相断开，自由停止 |
| 2 | MODE_BRAKE | `0x17` | `motor_set_brake()` | 无 | 三相接地，阻尼制动 |
| 3 | MODE_VOLT | `0x18` | `motor_set_dq_vlot()` | volt (V) | DQ 电压控制 |
| 4 | MODE_CUR | `0x19` | `motor_set_dq_current()` | cur (A) | DQ 电流控制 |
| 5 | MODE_TQE | `0x1A` | `motor_set_tqe()` | tqe (Nm) | 力矩控制 (含型号修正) |
| 6 | MODE_VEL | `0x1B` | `motor_set_vel()` | vel | 速度控制 |
| 7 | MODE_POS | `0x1C` | `motor_set_pos()` | pos | 位置控制 (最大速度) |
| 8 | MODE_VEL_ACC | `0x1D` | `motor_set_vel_acc()` | vel, acc | 速度+加速度 |
| 9 | MODE_POS_VEL_TQE | `0x1E` | `motor_set_pos_vel()` | pos, vel | 位置+速度 (力矩不限) |
|  |  |  | `motor_set_pos_vel_MAXtqe()` | pos, vel, tqe | 位置+速度+力矩限制 |
| 10 | MODE_POS_VEL_ACC | `0x1F` | `motor_set_pos_velmax_acc()` | pos, vel_max, acc | 梯形控制 |
| 11 | MODE_POS_VEL_TQE_KP_KD | `0x20` | `motor_set_pos_vel_tqe_kp_kd_2()` | pos, vel, tqe, kp, kd | MIT 运控模式 |

**调用示例 (普通单机模式):**
```c
// 速度模式
motor_set_vel(PORT1, TINT16, 1, 0.5f);  // 电机1以0.5 rps运行

// 梯形控制
motor_set_pos_velmax_acc(PORT1, TFLOAT, 1, 5.0f, 1.0f, 0.2f);

// MIT运控模式 (输出力矩 = 位置偏差*kp + 速度偏差*kd + 前馈力矩)
motor_set_pos_vel_tqe_kp_kd_2(PORT1, TINT16, 1, 2.0f, 0.1f, 1.0f, 1.0f, 1.0f);

// 查询并解析
motor_get_state_send(PORT1, TINT16, 1);   // 发送查询指令
HAL_Delay(1);
motor_process_state_all();                 // 解析响应帧 → 写入 motor_state_s
```

### 3.2 一拖多并联模式 (motor_many)

先对每个电机调用 `motor_many_*` 写缓存，最后调用一次 `motor_many_send()` 批量发送。固定使用 TINT16 数据类型。

| 序号 | 模式 | 模式码 | 写缓存函数 | 参数 | 每电机字节数 | ID块 |
|------|------|--------|-----------|------|------------|------|
| 1 | VOLTAGE | `0x80`/`0x83` | `motor_many_dq_volt()` | vol (V) | 2 | `0x80+id-1` |
| 2 | CURRENT | `0x84` | `motor_many_dq_current()` | cur (A) | 2 | `0x84+id-1` |
| 3 | TORQUE | `0x82` | `motor_many_tqe()` | tqe (Nm) | 2 | `0x82+id-1` |
| 4 | POSITION | `0x80` | `motor_many_pos()` | pos | 2 | `0x80+id-1` |
| 5 | VELOCITY | `0x81` | `motor_many_vel()` | vel | 2 | `0x81+id-1` |
| 6 | TIME_OUT | `0x85` | `motor_many_time_out()` | t_ms | 2 | `0x85+id-1` |
| 7 | VEL_ACC | `0x90` | `motor_many_vel_acc()` | vel, acc | 4 | `0x90`~`0x91` |
| 8 | POS_VEL_TQE | `0x92` | `motor_many_pos_vel()` | pos, vel | 6 | `0x92`~`0x94` |
|  |  |  | `motor_many_pos_vel_MAXtqe()` | pos, vel, tqe_max | 6 | `0x92`~`0x94` |
| 9 | POS_VEL_ACC | `0x95` | `motor_many_pos_vel_acc()` | pos, vel, acc | 6 | `0x95`~`0x97` |
| 10 | POS_VEL_TQE_KP_KD_2 | `0x98` | `motor_many_pos_vel_tqe_kp_kd_2()` | pos, vel, tqe, kp, kd | 10 | `0x98`~`0x9C` |

**调用示例 (一拖多并联模式):**
```c
// 假设 3 个电机并联
// 第1步: 逐电机写缓存
motor_many_vel(PORT1, 1, 0.1f);
motor_many_vel(PORT1, 2, 0.2f);
motor_many_vel(PORT1, 3, 0.3f);

// 第2步: 批量发送 (返回 模式/错误/位置/速度/力矩)
motor_many_send(PORT1, MANY_GET_MODE_FLAUT_POS_VEL_TQE);

// 第3步: 解析响应
motor_process_state_all();
```

## 四、CAN 帧格式详解

### 4.1 发送帧通用格式

```
┌──────────────┬────────────────────────────────┐
│ CAN ID       │ 0xTT000 | motor_id              │
│              │   TT: 08=TINT16, 10=TINT32, 18=TFLOAT │
│              │   或 0x8000|id (系统/查询命令)    │
├──────────────┼────────────────────────────────┤
│ Data[0]      │ mode (电机模式码)               │
│ Data[1]      │ query (查询码, 通常 0x06)       │
│ Data[2..N]   │ payload (小端序)                │
└──────────────┴────────────────────────────────┘
```

### 4.2 响应帧格式

#### 普通模式响应 (query 0x06)

| 数据类型 | CAN ID | 帧长 | Data[0] | Data[1] | Data[2] | Data[3..4/5] | Data[5..6/9] | Data[7..10/13] |
|---------|--------|------|---------|---------|---------|-------------|-------------|---------------|
| TINT16 | 0x08xxx | ≥9 | query | mode | fault | pos (int16) | vel (int16) | tqe (int16) |
| TINT32 | 0x10xxx | ≥15 | query | mode | fault | pos (int32) | vel (int32) | tqe (int32) |
| TFLOAT | 0x18xxx | ≥15 | query | mode | fault | pos (float) | vel (float) | tqe (float) |

#### 一拖多模式响应

| 查询类型 | 帧长 | Data[0] | Data[1] | Data[2..3] | Data[4..5] | Data[6..7] |
|---------|------|---------|---------|-----------|-----------|-----------|
| 0x11 (模式/错误/位置/速度/力矩) | 8 | mode | fault\|type | pos (int16) | vel (int16) | tqe (int16) |
| 0x12 (温度/错误/位置/速度/力矩) | 8 | temp | fault\|type | pos (int16) | vel (int16) | tqe (int16) |

> type = Data[1] >> 6，用于区分返回类型
> fault = Data[1] & 0x3F

#### 版本号响应

| Data[0] | Data[1] | Data[2] | Data[3] | Data[4] |
|---------|---------|---------|---------|---------|
| — | 0xB5 | 0x02 | patch\|minor(高4) | major(高4)\|minor(低4→高4) |

#### 型号查询响应

| Data[0] | Data[1] | Data[2..N] |
|---------|---------|------------|
| 0x07 | 数据长度 L | L 字节 (每字节低4位 = 1位十六进制ASCII码) |

## 六、关键宏定义

| 宏 | 值 | 说明 |

| `MOTOR_PORT_NUM` | `1` | CAN 通道数量 |
