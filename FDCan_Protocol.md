# **高擎电机 FDCAN 通信协议解析手册**

版本 1.0 | CAN FD | 29-bit 扩展帧 | 仲裁段 1M / 数据段 5M

## **1. 协议解析**

### **1.1 CAN ID**

29-bit 扩展帧，有效位 [19:0]：

**表 1 — CAN ID 位布局**

| **Bit** | **[29:19]** | **[18]**                                       | **[17:16]**                          | **[15]**                                         | **[14:8]** | **[7]**                                    | **[6:0]** |
| ------- | ----------- | ---------------------------------------------- | ------------------------------------ | ------------------------------------------------ | ---------- | ------------------------------------------ | --------- |
| 含义    | 保留        | CAN_MIT 模式                                   | 数据类型                             | 帧方向                                           | 发送端ID   | 一拖多标识                                 | 电机端ID  |
| 取值    | 均需为0     | 0=不启用 CAN_MIT 模式<br />1=启用 CAN_MIT 模式 | 01=int16<br />10=int32<br />11=float | 1=发送给电机的控制帧<br />0=接收电机状态的返回帧 | 1~126      | 1=启用一拖多协议<br />0=启用单电机控制协议 | 1~126     |

CAN ID = **标题宏 | 电机ID**。发送时**发送端 ID 填在末尾的低位** (`0x...XX`)，返回时**电机端 ID 与发送端 ID 位置互换**

例：**CAN ID 构成**（以电机 1 为例，int16 / int32 / float / MIT 各举一例）：

| 数据类型 | 发送标题宏 | 发送 CAN ID                 | 返回 CAN ID                      |
| -------- | ---------- | --------------------------- | -------------------------------- |
| int16    | 0x18000    | `0x18000 | 1` = **0x18001** | `0x10000 | (1<<8)` = **0x10100** |
| int32    | 0x28000    | `0x28000 | 1` = **0x28001** | `0x20000 | (1<<8)` = **0x20100** |
| float    | 0x38000    | `0x38000 | 1` = **0x38001** | `0x30000 | (1<<8)` = **0x30100** |
| MIT      | 0x58000    | `0x58000 | 1` = **0x58001** | `0x10000 | (1<<8)` = **0x10100** |

> 发送帧 ID 末尾为电机 ID（如 `0x18001`），返回帧 ID 中电机 ID 左移 8 位（如 `0x10100`），两者互为高/低位互换关系。

### **1.2 单电机发送帧**

每帧 = **模式码 (1字节)** + **查询码 (1字节)** + **参数 (小端序)**。通用结构如下
各模式的模式码、帧长、参数见 **表 2**（§3.3）
查询码含义见 §1.4，数据换算见 **表 5**（§3.3）：

| 字节 | **Byte0** | **Byte1** | **Byte2~N**         |
| ---- | --------- | --------- | ------------------- |
| 含义 | 模式码    | 查询码    | 参数 (小端序)       |
| 取值 | 0x01~0x21 | 0x0A~0x0C | 长度由模式/类型决定 |

#### **示例一：VEL 速度控制 (模式码 0x1C, int16)**

电机 1 以 0.1 圈/s 转动，数据类型 int16，CAN ID=0x18001：

|      | **CAN ID**           | **Byte0 (模式码)** | **Byte1 (查询码)** | **Byte2~3 (目标速度)**                                    |
| ---- | -------------------- | ------------------ | ------------------ | --------------------------------------------------------- |
| Hex  | 0x18001              | 1C                 | 0B                 | 90 01                                                     |
| 解析 | int16，发送帧，电机1 | 模式 VEL(0x1C)     | 查询码 0x0B        | 90 01 解析为 0x0190，十进制原始值 400 → 目标速度 0.1 圈/s |

#### **示例二：POS_VEL_TQE 位置+速度+力矩 (模式码 0x1F, int32)**

电机 1 以 0.5 圈/s 速度转到 0.5 圈位置，力矩上限 1.0 Nm，数据类型 int32，CAN ID=0x28001 (bit17=1)：

|      | **CAN ID**           | **Byte0 (模式码)**     | **Byte1 (查询码)** | **Byte2~5 (目标位置)**                                       | **Byte6~9 (最大速度)**                                       | **Byte10~13 (力矩上限)**                                     |
| ---- | -------------------- | ---------------------- | ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Hex  | 0x28001              | 1F                     | 0B                 | 50 C3 00 00                                                  | 50 C3 00 00                                                  | E8 03 00 00                                                  |
| 解析 | int32，发送帧，电机1 | 模式 POS_VEL_TQE(0x1F) | 查询码 0x0B        | 50 C3 00 00 解析为 0x0000C350，十进制原始值 50000 → 目标位置 0.5 圈 | 50 C3 00 00 解析为 0x0000C350，十进制原始值 50000 → 最大速度 0.5 圈/s | E8 03 00 00 解析为 0x000003E8，十进制原始值 1000 → 力矩上限 1.0 Nm |

#### **示例三：MIT 运控模式 (模式码 0x21)**

### **1.3 一拖多发送帧**

多个电机参数在同一帧内连续打包，**固定 int16，无 mode 头**（模式由 CAN ID 的 bits[6:0] 模式块编号决定），查询码放在发送帧的最后一个字节。

一拖多模式的 **CAN ID 与普通模式并不完全相同**：普通模式 bits[6:0] 存的是电机 ID，而一拖多模式下 bits[6:0] 存的是**模式块编号**（决定本帧控制哪种模式、装几个电机）。一拖多 CAN ID 位布局如下：

**一拖多 CAN ID 位布局表**

| **Bit** | **[17:16]**     | **[15]**             | **[7]**          | **[6:0]**               |
| ------- | --------------- | -------------------- | ---------------- | ----------------------- |
| 含义    | 数据类型        | 帧方向               | 一拖多标识       | 模式块编号              |
| 取值    | 01=int16 (固定) | 1=发送给电机的控制帧 | 见下方说明       | 0x80~0x9C (见 **表 4**) |

> **一拖多标识（bit[7]）说明**：模式块编号取值为 0x80~0x9C，其最高位 bit[7] 恒为 1，因此**一旦填入模式块编号，bit[7] 即自动置 1**，标识本帧启用一拖多协议，无需单独设置该位。

> 一拖多发送 CAN ID = `0x18000 | 模式块编号`。例如速度控制模式块 0x81 → **0x18081**；位置控制 0x80 → **0x18080**。返回帧 CAN ID = `0x00000 | (motor_id << 8)`（bit[7]=0，电机 ID 落回高 8 位）。

#### **示例：3 电机速度控制 (模式块 0x81, 查询码 0x0B)**

CAN ID=0x18081，每电机 2 字节 vel，末尾 1 字节查询码，共 7 字节：

|      | **CAN ID**                                    | **Byte0~1 (电机1)**                                         | **Byte2~3 (电机2)**                                          | **Byte4~5 (电机3)**                                          | **Byte6**   |
| ---- | --------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ----------- |
| Hex  | 0x18081                                       | 90 01                                                       | D0 07                                                        | A0 0F                                                        | 0B          |
| 解析 | int16，一拖多，模式块 0x81 (VEL)，查询码 0x0B | 90 01 解析为 0x0190，十进制原始值 400 → 电机1 速度 0.1 圈/s | D0 07 解析为 0x07D0，十进制原始值 2000 → 电机2 速度 0.5 圈/s | A0 0F 解析为 0x0FA0，十进制原始值 4000 → 电机3 速度 1.0 圈/s | 查询码 0x0B |

#### **示例：速度+加速度 (模式块 0x90, 查询码 0x0B)**

CAN ID=0x18090，2 个电机，每电机 vel(2字节)+acc(2字节)，末尾查询码，共 9 字节：

|      | **CAN ID**                                        | **Byte0~1 (电机1.vel)**                                        | **Byte2~3 (电机1.acc)**                                         | **Byte4~5 (电机2.vel)**                                         | **Byte6~7 (电机2.acc)**                                         | **Byte8**   |
| ---- | ------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ----------- |

| 解析 | int16，一拖多，模式块 0x90 (VEL_ACC)，查询码 0x0B | 90 01 解析为 0x0190，十进制原始值 400 → 电机1 速度 0.1 圈/s | E8 03 解析为 0x03E8，十进制原始值 1000 → 电机1 加速度 1.0 圈/s² | D0 07 解析为 0x07D0，十进制原始值 2000 → 电机2 速度 0.5 圈/s | D0 07 解析为 0x07D0，十进制原始值 2000 → 电机2 加速度 2.0 圈/s² | 查询码 0x0B |

#### **示例：位置+速度+加速度 (模式块 0x95, 查询码 0x0B)**

CAN ID=0x18095，2 个电机，每电机 pos(2字节)+vel(2字节)+acc(2字节)，末尾查询码，共 13 字节：

|      | **CAN ID**                                            | **Byte0~1 (电机1.pos)**                                       | **Byte2~3 (电机1.vel)**                                         | **Byte4~5 (电机1.acc)**                                         | **Byte6~7 (电机2.pos)**                                        | **Byte8~9 (电机2.vel)**                                         | **Byte10~11 (电机2.acc)**                                       | **Byte12**  |

### **1.4 返回帧（通用）**

单电机与一拖多返回帧结构相同：Byte 0 = **查询码**，Byte 1 = **模式码**，Byte 2 = **错误码**，后续为查询数据 (小端序)。返回帧 CAN ID = 0x10000 + motor_id × 256 (如电机1 → 0x10100)。

#### **查询码与返回参数**

发送帧 Byte 1 (查询码) 决定电机返回哪些数据，查询码原样回传至返回帧 Byte 0：

| **查询码** | **含义**   | **返回参数**                            | **int16 帧长** |
| ---------- | ---------- | --------------------------------------- | -------------- |
| 0x0A       | 控制次数   | query, mode, fault, NUM                 | 5 字节         |
| 0x0B       | 标准状态   | query, mode, fault, pos, vel, tqe       | 9 字节         |
| 0x0C       | 含温度状态 | query, mode, fault, temp, pos, vel, tqe | 11 字节        |

#### **示例：查询码 0x0B (标准状态)**

CAN ID=0x10100 (电机 1), 数据 = 0B 1C 00 C8 00 90 01 03 00

|      | **CAN ID**                                | **Byte0**   | **Byte1**      | **Byte2**            | **Byte3~4**                                              | **Byte5~6**                                               | **Byte7~8**                                            |
| ---- | ----------------------------------------- | ----------- | -------------- | -------------------- | -------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| Hex  | 0x10100                                   | 0B          | 1C             | 00                   | C8 00                                                    | 90 01                                                     | 03 00                                                  |
| 解析 | int16，返回帧，电机1 (CAN ID=0x10000+256) | 查询码 0x0B | 模式 VEL(0x1C) | 错误码 0x00 (无错误) | C8 00 解析为 0x00C8，十进制原始值 200 → 当前位置 0.02 圈 | 90 01 解析为 0x0190，十进制原始值 400 → 当前速度 0.1 圈/s | 03 00 解析为 0x0003，十进制原始值 3 → 当前力矩 0.03 Nm |

#### **示例：查询码 0x0C (含温度状态)**

CAN ID=0x10100 (电机 1), 数据 = 0C 1C 00 FA 00 C8 00 90 01 03 00

|      | **CAN ID**                                | **Byte0**   | **Byte1**      | **Byte2**          | **Byte3~4**                                         | **Byte5~6**                                          | **Byte7~8**                                           | **Byte9~10**                                       |
| ---- | ----------------------------------------- | ----------- | -------------- | ------------------ | --------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------- | -------------------------------------------------- |
| Hex  | 0x10100                                   | 0C          | 1C             | 00                 | FA 00                                               | C8 00                                                | 90 01                                                 | 03 00                                              |
| 解析 | int16，返回帧，电机1 (CAN ID=0x10000+256) | 查询码 0x0C | 模式 VEL(0x1C) | 错误码 0x00 (正常) | FA 00 解析为 0x00FA，十进制原始值 250 → 温度 25.0°C | C8 00 解析为 0x00C8，十进制原始值 200 → 位置 0.02 圈 | 90 01 解析为 0x0190，十进制原始值 400 → 速度 0.1 圈/s | 03 00 解析为 0x0003，十进制原始值 3 → 力矩 0.03 Nm |

## **3. 附录**

### **3.1 系统命令**

统一使用 int16 (CAN ID=0x18001 等)，多数无返回值：

| **功能**      | **发送帧**  | **说明**           |
| ------------- | ----------- | ------------------ |
| 停止          | 01 0B       | 三相断开，自由停转 |
| 刹车          | 18 0B       | 三相接地，阻尼制动 |
| 软重启        | 03 03 01    | 电机软复位         |
| 保存设置      | 03 03 02    | 参数写入 Flash     |
| 重设零位      | 03 03 03    | 当前位置设为 0     |
| 修改 ID (1→2) | 03 03 04 02 | 新 ID=2            |
| 超时 500ms    | 05 1F F4 01 | 无指令自动刹车     |
| 周期返回 1ms  | 03 00 05 0B E8 03 00 00 | 每 1000us 返回一次状态，返回格式同查询码 0x0B |

`03 03` 系列：Byte0=系统命令类型, Byte1=子类别, Byte2=操作码 (01=复位/02=保存/03=设零/04=改ID+Byte3=新ID)超时命令：Byte0=05, Byte1~2=超时值 0x01F4=500ms (小端)周期返回命令：Byte0=03, Byte1=00, Byte2=05, Byte3=0B, Byte4~7=周期微秒值 (4字节小端, 0=停止周期返回)

### **3.2 版本查询**

发送 `00 04` 查询固件版本 (CAN ID=0x18001)，返回 5 字节：

| **字节** | **0** | **1** | **2** | **3**           | **4**           |
| -------- | ----- | ----- | ----- | --------------- | --------------- |
| 内容     | —     | B5    | 02    | patch, minor高4 | major, minor低4 |

版本 = major.minor.patch。硬件版本查询 (`00 05`) 格式相同，Byte[2]=03。型号查询 (`00 07`)：返回首字节 0x07 + 长度 + 型号码 (每字节低4位拼合)，如 `5036_02`。
